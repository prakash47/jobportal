# @jobportal/recruiter

Recruiter portal for JobPortal. Next.js 16 (App Router, Turbopack, React 19.2).

**Production subdomain:** `recruit`

## Scripts

```bash
pnpm --filter @jobportal/recruiter dev       # http://localhost:3001
pnpm --filter @jobportal/recruiter build
pnpm --filter @jobportal/recruiter typecheck
```
